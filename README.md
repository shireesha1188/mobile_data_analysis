# 📱 Mobile Usage Data Analysis

A complete SQL-based exploratory data analysis (EDA) project on user mobile behavior across different age groups, locations, and usage patterns. This project helps uncover insights into device preferences, screen time, primary use cases, and demographic distributions.

🧰 Tools & Technologies Used
.Data Source: Excel
.Data Cleaning & Transformation: Python (Pandas)
.Database: SQL Server
.Data Analysis: T-SQL (Window Functions, CTEs, Aggregations, Pivots,sub_query)
.Data visualization: Power BI


## 📊 Key Insights

1.Younger users (18-25) show higher daily screen time, social media usage, and gaming time, while older users (45+) have higher monthly recharge costs.

2.Samsung is the most popular phone brand, and Android is the dominant operating system, indicating a significant market share.

3.There are subtle gender-based differences in usage, with females spending slightly more time on streaming and males spending more on gaming.

4.Users with high social media and streaming usage have correspondingly high monthly data consumption.

5.Higher screen time and engagement with streaming and social media correlate with increased monthly e-commerce spending.

6.The project successfully segments users based on their Primary Use, such as 'Entertainment' or 'Education', which helps to understand the main drivers of mobile phone usage.
